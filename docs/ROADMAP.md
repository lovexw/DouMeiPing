# 抖美评 · 发展路线图与开发规划

> 本文档是项目的「外置记忆」：记录整体规划、架构决策与当前进度。
> 约定：每完成一个阶段，更新「六、当前状态」并提交到 git，保证新会话 / 新协作者读到本文件即可接手，无需历史聊天记录。

## 一、产品定位与红线

**定位**：默默好赞评价管理助手 · 默默传媒 — 门店评价内容与口碑运营工具。**不是帮商家制造好评，而是帮助真实体验被更好地表达**；在算法时代，让真实的消费体验成为门店的线上内容资产。分行业写实词库 + 组合算法，参考生成 → 复制 → 直达平台评价页。

**合规红线（业务存续问题，所有宣传与文案必须遵守）**：
- 产品永远定位为「评价表达辅助工具」，强调「基于真实体验的参考模板，发布前请顾客确认」
- 对外宣传永不出现「刷好评」「必爆」「保证排名」「流量加权 / 曝光加权」等字眼（广告法 + 平台风控 + 小程序审核）
- **因果口径降级**：只说「评价是平台判断商户的重要内容信号之一，优质真实持续的评价有助于完善消费者认知、可能影响平台侧综合经营表现」；永不承诺曝光 / 排名 / 评分结果（依据：美团规则中心公开的星级与排序综合因素）
- **对外唯一口径基准**：docs/话术清单.md —— 销售、客服、官网、演示页、物料、AI 自动回复全部以其为准，新触点上线前过一遍其红线词库
- 保留同门店生成的防重复 / 节奏控制设计，这是风控需要，不是可选项

## 二、核心架构决策（总纲）

**把「改代码」变成「改数据」**。开发者主要靠 AI 编程，每次发版都是完整的开发+审核周期，所以：

| 层 | 内容 | 变化频率 | 载体 |
| --- | --- | --- | --- |
| 引擎层（代码） | 生成算法、页面 UI、跳转逻辑 | 半年不动一次 | git 仓库，稳定后冻结 |
| 数据层（云端） | 商家配置、行业词库、商家专属词库 | 天天在变 | 微信云开发（云数据库 + 云函数 + Content CMS） |

选型理由：云开发免服务器、免备案、免运维，按量付费有免费额度；自带 Content CMS 可视化管理数据，运营者无需写代码即可增删商家、改词库、重置访问码。

**判定习惯**：接到任何需求，先判断是「数据问题」还是「代码问题」——90% 应该是数据问题，用后台解决；只有引擎层才动代码。

## 三、词库分层设计（解决词库庞大 + 定制工作量）

- **L1 行业通用库**：每行业一套（咖啡 / 火锅 / 烧烤……），同行业商家共享，批量维护
- **L2 商家专属库**：年卡定制文案单独存表（按门店 ID 关联），生成时按比例与 L1 混合抽取
- 效果：一个商家一年定制 3 次 = 在 CMS 里加 10~20 条专属文案（约 5 分钟），**工作量是每商家常数，不随商家总数增长**
- 词库再大也只是数据库行数；后续可做「商家填表单提交定制需求 → 审核入库」的自助流程

## 四、运营与差异化

**管理后台**：P2 用云开发 Content CMS 覆盖 80% 需求；统计看板（生成次数 / 活跃门店 / 行业分布 / 续费提醒）放 P3，且依赖生成走云函数后才有数据。

**拉开差距的三条线**（功能本身一周可被抄走，壁垒在沉淀）：
1. **数据沉淀**：生成量、行业分布、续费率的真实数据 → 看板、行业报告
2. **服务纵深**：词库定制响应、开通时效、行业覆盖广度（目标 20+）；延伸功能——评价回复模板（与生成共用词库逻辑，低成本高价值）、差评预警、评价数据月报
3. **渠道绑定**：城市代理 / 本地服务商关系，抄不走

**推广全国**：产品无地域限制，瓶颈在渠道。
- 城市代理模式：代理子账号 / 代理后台，代理签约本地商家按年费分成，边际成本≈0
- 获客：抖音 / 视频号内容（「餐饮老板如何拿平台流量」选题）、门店桌贴二维码物料（顾客扫码进小程序，零成本自传播）
- 定价分层：月卡（低门槛）/ 年卡（主力）/ 代理版（批发价）

## 五、分阶段路线图

### P1 最小改造（1~2 周）
- **目标**：新商家开通不发版。商家配置（STORES）从代码挪到云端，小程序启动时拉取 + 本地缓存兜底
- **做法**：可先挂一个线上 JSON（任意静态托管 / 云存储）做过渡，不必一步到位上云开发
- **验收标准**：CMS（或改 JSON）里加一家新门店，小程序内输入访问码直接可用，全程无发版
- **同步动作**：用现有产品签 10~20 个种子商家，验证付费意愿

### P2 全面数据化（约 1 个月）
- 商家配置 + 词库全量上云数据库；生成改走云函数（服务端防重复、可统计、可灰度）
- 开通云开发 Content CMS 作为运营后台；加商家、改词库零代码
- 访问码体系升级评估：明文访问码 → 扫码 / 一次性链接（可留到 P3）

### P3 增值功能（2~3 个月）
- 商家专属词库定制流程化（需求表单 → 审核入库 → L2 生效）
- 门店桌贴二维码物料体系
- 评价回复模板（复用词库逻辑）
- 基础数据看板

### P4 规模化（3~6 个月）
- 代理后台与分成体系、行业词库扩到 20+
- 差评预警、评价数据月报等差异化功能
